Lecturers

Share data with all lecturers (GitHub)

Data is stored as one file, lecturer-data.json, in a GitHub repository. Everyone who connects to the same repository sees the same records. Your token stays in this browser only.

Set up other lecturers with one link

Once you are connected, create a setup link and send it to your colleagues (for example on WhatsApp). When they open it, the page connects itself. They need no GitHub account. Treat the link like a password: anyone who has it can edit your lab records.

Restore an earlier version (admin)

GitHub keeps every saved version of the data file. If something was changed or deleted by mistake, load the earlier versions, pick the one you want, and restore it. Everyone's page follows after its next sync.

Freeze the setup lists (admin)

When frozen, your coworkers can still see the lists but cannot add, rename, edit or delete anything in them. You keep full control on your own page.

Backup and restore

Data is saved in this browser only. Download a backup regularly, and use it to move to another phone or computer.
